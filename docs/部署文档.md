# 部署文档
环境：CentOS 7 / VMware / 2C2G / 20GB 磁盘

## 一、用户管理 + SSH 安全加固
**1. 创建运维用户**
```
sudo useradd -m -s /bin/bash ops
sudo passwd ops
```
**2. 赋予用户sudo权限**
```
sudo visudo -f /etc/sudoers.d/ops
```

> 权限文件内容：ops ALL=(ALL) NOPASSWD:ALL
> ops 用户执行任意 sudo 命令，免密提权。
```
#切换到ops用户
su - ops
```
**3. SSH密钥登录**
>用本地生成的密钥对代替密码认证，实现免密自动登录，是脚本自动化非交互式认证的刚需；同时避免密码泄露、暴力破解和中间人攻击。

在本机（Windows宿主机）生成密钥对
```
#本机powershell执行
ssh-keygen -t ed25519 -f C:\Users\lenovo/.ssh/id_ed25519 -N ""
```
在虚拟机中加入公钥，修改权限
```
mkdir -p /home/ops/.ssh
echo "ssh-ed25519 AAAAC3... 你的完整公钥" >> /home/ops/.ssh/authorized_keys
chmod 700 /home/ops/.ssh
chmod 600 /home/ops/.ssh/authorized_keys
```
验证：cmd中可以无密码ssh登录即为成功
```
ssh ops@ip地址
```
**4. 禁用root密码登录**

> 关闭 root 账户的密码认证入口，即使攻击者拿到 root 密码也无法远程登录，所有管理操作必须通过普通用户 + sudo 执行，形成可审计的安全基线。
> ⚠️ 修改前确认 ops 用户密钥登录已成功，不然会把自己锁在外面。

```
sudo sed -i 's/^PermitRootLogin yes/PermitRootLogin prohibit-password/' /etc/ssh/sshd_config  
sudo sed -i 's/^#PasswordAuthentication yes/PasswordAuthentication no/' /etc/ssh/sshd_config  
sudo systemctl restart sshd
```
**5. 防火墙设置**
```
sudo systemctl start firewalld  
sudo systemctl enable firewalld  
sudo firewall-cmd --permanent --add-service=ssh  
sudo firewall-cmd --permanent --add-service=http  
sudo firewall-cmd --permanent --add-service=https  
sudo firewall-cmd --reload  
sudo firewall-cmd --list-all
```
## 二、Nginx 与 MySQL 安装管理
**1. Nginx安装与管理**

安装
```
sudo yum install -y epel-release
sudo yum makecache
sudo yum install -y nginx
```
管理
```
# 启动  
sudo systemctl start nginx  
# 停止  
sudo systemctl stop nginx  
# 重启  
sudo systemctl restart nginx  
# 重新加载配置（不中断服务）  
sudo systemctl reload nginx  
# 设置开机自启  
sudo systemctl enable nginx  
# 查看是否已设置自启  
sudo systemctl is-enabled nginx
```
配置文件检查与日志
```
# 检查配置文件语法  
sudo nginx -t  
# 查看错误日志  
tail -f /var/log/nginx/error.log  
# 查看访问日志  
sudo tail -100 /var/log/nginx/access.log
```

**2. MySQL安装与管理**
安装
```
# 安装 MySQL（CentOS 7 需先添加官方仓库）  
sudo yum install -y https://dev.mysql.com/get/mysql80-community-release-el7-7.noarch.rpm  
sudo yum install -y mysql-community-server  
# 检查运行状态  
sudo systemctl status mysql  
# 安全初始化  
sudo mysql_secure_installation
```

> 在mysql_secure_installation中：
>  • 设置 root 密码 
>  • 移除匿名用户 → Y
>   • 禁止 root 远程登录→ Y 
> • 移除 test 数据库 → Y

管理
```
sudo systemctl stop mysqld  
sudo systemctl start mysqld  
sudo systemctl restart mysqld  
sudo systemctl enable mysqld
```
用户与日志配置
```
--MySQL中执行
CREATE DATABASE IF NOT EXISTS myapp;  
CREATE USER "appuser"@"localhost" IDENTIFIED BY "App_pass_123";  
GRANT ALL PRIVILEGES ON myapp.* TO "appuser"@"localhost";  
FLUSH PRIVILEGES;  
EXIT;
```
**3. redis安装与管理**
安装
```
sudo yum install -y redis  
redis-server --version
```
配置
```
sudo mkdir -p /var/log/redis  
sudo chown redis:redis /var/log/redis  
sudo vim /etc/redis.conf
```
```
#redis.conf中配置
bind 127.0.0.1  
port 6379  
requirepass redis_pass_123  
logfile /var/log/redis/redis.log
```
管理
```
sudo systemctl start redis
sudo systemctl enable redis
```
## 三、部署应用＋Nginx反向代理
**1. 安装Node.js**
```
#下载nvm 
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash 
#加载环境变量 
source ~/.bashrc 
#安装node16（LTS，兼容glibc2.17） 
nvm install 16 
#启用并设置默认版本 
nvm use 16 
nvm alias default 16 
#验证 
node -v 
npm -v
```
**2. 创建应用**
```
mkdir -p ~/project/app  
cd ~/project/app  
npm init -y  
npm install express@4 mysql2@3 redis@3
```
~/project/app目录下编写[app.js](https://github.com/JonathanAi293/project1_production_env_deployment/blob/main/app/app.js)
放行应用所需端口
```
sudo firewall-cmd --add-port=3000/tcp --permanent
sudo firewall-cmd --reload
```
**3. 用systemd管理应用**
创建 /etc/systemd/system/[myapp.service](https://github.com/JonathanAi293/project1_production_env_deployment/blob/main/configs/myapp.service)
```
sudo systemctl daemon-reload   #重新读取配置
sudo systemctl start myapp  
sudo systemctl enable myapp  
systemctl status myapp  
curl -I http://127.0.0.1:3000 # 应返回 200 OK
```
**4. Nginx反向代理配置**
创建 /etc/nginx/conf.d/[myapp.conf](https://github.com/JonathanAi293/project1_production_env_deployment/blob/main/configs/myapp.conf)
```
server {  
listen 80;  
server_name myblog.example.com;  
  
location / {  
proxy_pass http://127.0.0.1:3000;  
proxy_set_header Host $host;  
proxy_set_header X-Real-IP $remote_addr;  
proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;  
}  
  
access_log /var/log/nginx/myapp.access.log;  
error_log /var/log/nginx/myapp.error.log;  
}
```
检查并重启nginx服务
```
sudo nginx -t  
sudo systemctl reload nginx  
```

> myapp.conf中使用的域名未注册，要想在宿主机浏览器访问，要先在C:\Windows\System32\drivers\etc\hosts中配置Ip与域名对应关系。

**5. 验证**
浏览器访问[myblog.example.com](http://myblog.example.com/)跳出应用页面

## 四、HTTPS
**1. 自签名证书（无域名测试用）**
```
sudo mkdir -p /etc/nginx/ssl  
sudo openssl req -x509 -nodes -days 365 -newkey rsa:2048 \  
-keyout /etc/nginx/ssl/myblog.key \  
-out /etc/nginx/ssl/myblog.crt \  
-subj "/CN=myblog.example.com"
```
**2. 配置https**
在 /etc/nginx/conf.d/[myapp.conf](https://github.com/JonathanAi293/project1_production_env_deployment/blob/main/configs/myapp.conf) 中增加 443 server 并强制跳转

**3. 验证**
- 浏览器通过 https 访问页面，HTTP 自动跳转 HTTPS；
- 证书信息正确。记录 DNS、证书有效期、安全组配置。
```
#证书信息重点看三项：
#subject的 CN 是否等于你的域名（CN=myblog.example.com）
#issuer签发机构（自签名会是你的 CN；Let's Encrypt 会是R3）
#notBefore / notAfter 有效期范围，今天必须在区间内
sudo openssl x509 -in /etc/nginx/ssl/myblog.crt -noout -subject -issuer -dates
```

## 五、备份脚本
**1. 创建脚本目录**
```
mkdir -p ~/project/scripts  
cd ~/project/scripts
```
**2.编写 [backup.sh](https://github.com/JonathanAi293/project1_production_env_deployment/blob/main/scripts/backup.sh)**
**3. 赋予执行权限并测试**
添加执行权限
```
chmod +x ~/project/scripts/backup.sh
```
插入测试数据
```
mysql -u root -p -e "CREATE TABLE myapp.test_table (id INT); INSERT INTO myapp.test_table VALUES (1), (2), (3);"
```
执行备份脚本
```
~/project/scripts/backup.sh
```
**4. 验证恢复**
模拟数据丢失
```
mysql -u root -p -e "DROP DATABASE myapp;"
mysql -u root -p -e "CREATE DATABASE myapp;"
```
从最新备份恢复
```
gunzip -c ~/backups/myapp_20260729_012413.sql.gz | mysql -u root -p myapp
```
确认数据恢复  
```
mysql -u root -p -e "SELECT * FROM myapp.test_table;"
```

## 七、定时任务
**1.  配置备份与巡检**
```
crontab -e

# 每天凌晨 2:00 执行数据库备份  
0 2 * * * /home/ops/project/scripts/backup.sh >> /home/ops/backups/backup.log 2>&1  
  
# 每天早上 8:00 和晚上 20:00 执行健康巡检  
0 8 * * * /home/ops/project/scripts/healthcheck.sh  
0 20 * * * /home/ops/project/scripts/healthcheck.sh
```
**2. 验证定时任务**

```
crontab -l  
grep CRON /var/log/cron # 确认任务真的触发
```
